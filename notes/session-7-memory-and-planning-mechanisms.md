**Paper**
- Title: MemGPT: Towards LLMs as Operating Systems
- Authors: Greg D. K. (Team MemGPT), et al.
- Year: 2023
- Link: https://arxiv.org/abs/2310.08560

**Overview**
- Introduces hierarchical memory with retrieval triggers for persistent context.

**Key Ideas**
- Separation of short-term buffers and long-term stores; event-triggered recall.

**Methods / Evidence**
- Agent demos and memory evaluations.

**Limitations**
- Memory corruption and retrieval precision; scaling costs.

**Discussion Questions**
- What triggers best support useful recall without noise?
- How to measure memory faithfulness over long horizons?
- Integration with planning/search modules.
